## 第一轮：整表行展平

参考 [Foofah 的 f_wrap_one_row](https://github.com/umich-dbgroup/foofah/blob/970864cd53b4c774a3dbdf4589d207f57ec63208/foofah_libs/operators.py)，上游 MIT。仅参考公开操作语义，独立用 MoonBit 实现 `FlattenRows`，没有复制 Python 实现。

`["flatten_rows"]` 将非空表按行展平为一行，保留空格与空单元格，输出使用通用列名；超过64列报错。旧管道编码不变。两批不同大小的训练表可明确整表意图。单批训练不能一般性区分整表与固定组，默认仍保留固定分组优先级；不使用留出答案决定排名。

验证：JS、Wasm GC、Wasm 各148项通过；API/CLI及24项高级浏览器流程通过。完整Foofah首候选196/225、候选上界207/225，未出现原通过任务回退。测试数据未进入学习请求；基准已参与开发，不是盲测。
