## 表格任务

完整 Foofah 250 个 exp0 文件包含 50 个任务族。25 个文件的测试答案为占位值，保留在库存和训练统计中，225 份有实际测试答案的文件全部进入泛化分母。5 个超过输入列数限制的文件均属于缺答案集。学习器只接收输入训练表和目标训练表。[上游版本和许可](../fixtures/foofah/README.md) · [逐题结果](evidence/benchmark-v0.5.1.json)

旧新各跑三轮，交替先后顺序，逐题的训练、首候选及事后候选上界判定稳定。本次 0 道新增首候选通过，0 道回退，两个版本都有 67/225 道首候选未通过。245/250 道报告搜索截断。题目及任务族变体参与过迭代开发，已有成功题不会从清单删除。[六轮对照](evidence/comparison-v0.5.0-v0.5.1.json) · [v0.5.0 历史报告](https://github.com/zhangbowen2006/ExampleLoom/blob/v0.5.0/docs/BENCHMARKS.md)

## 字符串任务

固定 SyGuS 2017 PBE Strings 赛道的全部 108 份文件。去重各文件内的相同输入后，4 份文件存在同一输入对应矛盾答案，按名记录排除，其余 104 份全部评估。将输入元组按 SHA-256 排序，前 `min(6,n−1,ceil(2n/3))` 条用于训练，其余全用于测试。测试输入和答案均不参与搜索。将完全相同的训练与留出拆分合并后为 51 个拆分，题族内部仍有关联。[上游固定题库](https://github.com/SyGuS-Org/benchmarks/tree/13c8deb68a873635879c9a69bc78caebd340f646/comp/2017/PBE_Strings_Track) · [完整拆分摘要与逐题结果](evidence/sygus-v0.5.1.json)

新增成功来自 initials 的四个文件与 univ_1 的两个文件，对应三个不同的训练/测试拆分。四个 initials 文件包含重复和相关数据。82 到 88 的文件成功数也记录了这种重复。旧版成功文件本次无回退，仍有 16/104 份首候选未达到全对，其中四份存在训练一致候选。新版 100/104 份报告搜索截断，两个版本均无超时或运行错误。

该评估执行输入输出转换，未限制程序必须属于原 SyGuS 题目的竞赛语法。题库用于复现和诊断，不由该成绩推断一般生产准确率。上游根目录未提供统一许可文件，原题下载到本地忽略目录中，公开记录只包含文件名、哈希和运行统计。

## 搜索工作量与耗时

Foofah 外层统一上限为 4 步、128 状态、2000 次结构尝试和 8 候选。SyGuS 统一上限为 8 候选、6 拼接段、4000 次原子求值、30000 步和 1024 个前沿状态。新版增加 Token 前后缀原子，并在预算允许时计算后缀成本下界，计入同一总步数。相同步数上限下，原子类型及其求值代价会随版本变化。

每题使用独立 Worker 和 5 秒墙钟上限。合成耗时从调用学习器开始计算，Worker 启动和测试重放计入超时判定。表格耗时是每版三轮分位数的中位数，字符串是每版一轮，逐文件交替两版先后顺序。Windows / i7-14650HX / Node v24.22.1 是本轮环境，CPU 负载也会影响结果。该轮表格分位数略降、字符串分位数上升，最大耗时及全部单次结果同时保留。

候选中任意一个答对是测试答案事后计算的上界。产品需由使用者选择程序，第一候选固定后才核验测试答案。原始任务与结果分母保持一致。ExampleLoom 各版本的同机比较没有测量 PROSE 或 Foofah 本体的速度。

本轮引擎 SHA-256 为 `5015894918a893a449ef86d67cb8c0ad1480a51c37ae2dc5b57ca897d80fd3e0`，测量代码位于[固定源码版本](https://github.com/zhangbowen2006/ExampleLoom/tree/209a77269409f209f38b34a84c1624dfbf8754db)。
