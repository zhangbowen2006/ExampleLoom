# Foofah 外部任务评估（2026-11-10）

本轮使用上游 MIT 许可的原始任务，而非自行为实现编造的测试集。完整收录固定提交的 250 个 exp0 文件（50 个任务族，每族 5 种样例数量），不按成功与否筛选。[来源与许可](../fixtures/foofah/README.md)、[文件哈希](../fixtures/foofah/manifest.json)。这些任务参与过本轮开发，不是盲测。

## 方法与避免泄漏

1. 原始所有网格行均作为字符串数据，包括可能存在的表头；仅适配为 c0、c1…列名，不根据答案猜测表头。
2. 学习器只接收 InputTable / OutputTable。首候选在看到 TestingTable / TestAnswer 之前固定。每个返回候选都重新执行并核对训练表。
3. 用同一管道执行上游 TestingTable，与 TestAnswer 逐格、逐列名、逐行序严格比较；空字符串和前导零有意义。执行报错也计失败，不删除困难记录。
4. 上游测试表与训练表并非总是完全不重叠；每个任务保留 overlapping_input_rows，任务族存在相关性。不能把 250 个任务当成 250 次独立业务试验。
5. 每任务独立 Worker，壁钟限 5000ms；默认深度 4、128 状态、2000 次结构尝试、8 候选。所有任务使用相同参数，不按任务名写转换特例。
6. 比较的是本项目在独立来源任务上的结果，没有安装运行原版 Foofah/PROSE，不填写它们的成功率或耗时。未从它们的论文数字推导同机优劣。

## 失败与限制

训练一致率明显高于测试通过率，说明过拟合仍然存在。完整结构语法、候选参数覆盖和搜索截断仍是主要差距；结果不能支持“任意表格转换”“接近成熟系统全部能力”或“已达到一般生产准确率”的声明。没有客户采用证据。

未覆盖/不完整的方向包括数值聚合、多表关系连接、任意列子集与复杂嵌套布局、任意组合的条件与结构联合合成，以及自动正则模式/替换模板学习。解释器能执行某个算子，不等于自动学习器能发现其所有参数。扩大搜索前还应解决状态内存、候选排名和不确定性提示。

## 复现

```sh
python scripts/import-foofah.py
node scripts/build.mjs
node scripts/benchmark.mjs
```

已有来源文件在本地时，第一个命令离线校验；缺文件/哈希错会失败。脚本写入所有失败和计数。`BENCHMARK_TIMEOUT_MS` 可显式改壁钟上限；改参数后的结果需另行标记，不能与本表混用。
