# 供本人写申报书的事实材料

**本文件是工程事实材料，不是本人创作声明或正式申报。** 参赛者应核对实现与来源，并按向组委会确认的规则提交。

- 项目名称：ExampleLoom（示例织机），示例驱动的数据转换引擎与独立工作台。
- 核心语言：MoonBit。核心解析、程序搜索、解释执行、日期校验、歧义选择、配方与批处理均为 MoonBit；JS 是界面、文件 I/O 与调用适配。
- 独立性：不依赖维护者旧项目、Excel、PROSE SDK 或云 API。新目录、新代码和新历史；没有复制旧项目核心代码。
- 功能与准确边界：见 README、ARCHITECTURE；不要写成通用 AI、任意表格转换、自动保证正确、算法首创、全球无竞品。
- 场景：v0.3 建议重点核对条件供应商编码、上下文正则 ref 捕获、宽表到长表；另有连续行打包和含空表头的 Melt 流程。完整输入、操作、输出与验证见 CAPABILITIES 和 examples。这些是构造数据演示，不是客户采用证明。
- 核心技术：有限 DSL 的输出引导搜索、保留多种解释、真实行上的分歧分组、带预算状态、可移植 AST、按列名绑定、多字段批处理。PBE 与交互消歧已有成熟研究，项目贡献是独立实现与可用交付。
- 测试与运行证据：见 VALIDATION。申报时核对当前 commit SHA、测试数量和公开仓库状态，不能把配置了 CI 写成远程 CI 已通过。
- 来源与许可证：README/RESEARCH，独立代码 MIT，基础 core Apache-2.0。无上游源码移植；概念参考需要如实披露。
- 竞争与风险：Flash Fill、PROSE、Foofah 已解决相关问题。MoonBit 现有显式数据转换库功能较广；本项目不声称全面替代它们。新颖性判断仍取决于评委，后续需要真实用户和更广泛测试。
- 已有项目：AgentCanary 的策略回放与本项目不同，不能写成已被驳回。WasmSlim/MoonGate 的问题没有通过改名或换账号绕过。
