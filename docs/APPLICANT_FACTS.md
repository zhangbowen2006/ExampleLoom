# 供本人写申报书的事实材料

v0.10 当前事实：扩展正则支持原子组与占有量词；可学习首键标识的重复键值记录转表，手写管道可选择保留新增输入列。用户需核对分段约定和候选，不能宣称完整 PCRE 或任意表格转换。Foofah 首候选 196/225，仍有 29 道未通过；这些题参与过开发。[逐题结果和边界](BENCHMARKS.md)

v0.9 历史事实：24 类表格操作，新增保留结构变化字段的列更新，并能从样例学习三类变长或分组报表转换；新增有限可变宽度后向断言、忽略大小写反向引用和大括号十六进制转义。相同 Foofah 口径首候选为 195/225，30 道未通过，逐题对比 v0.8 多通过 16 道、无首候选回退。

v0.8 历史事实：条件、23 类表格操作、稳定排序及补样流程保留；此前增加显式扩展正则、断言、命名捕获及替换、反向引用和执行限额，可用于条件、学习提示及表格管道。131 项 MoonBit 测试中含 5 项保留的上游 Unicode 测试；23,940 项构造正则差分和三个新增流程通过。新正则底层按 Apache-2.0 采用并修改 MoonBit 上游实现，不能申报为本项目原创算法。[初审对应与限制](REGEX_PROFILE.md) · [来源清单](../LICENSES/moonbit-regexp.NOTICE)。`wide-table-regex` 四步表格示例是显式编写的程序，不能声称整条由学习器推导。

v0.8 完整重放中，Foofah 首候选为 179/225，SyGuS 每题最多 32 条训练的新口径为 104/104，去重后为 51/51。v0.6.0 已有的每题最多六条训练旧口径为 101/104；训练拆分改变，引用成绩必须注明口径。四份矛盾原题及历史 46 道失败均在记录中保留。IANA 的 282 条留出时区记录按地区展开并计数后与 SQLite 全部一致。分母、重合变体和失败见[基准报告](BENCHMARKS.md)。

**本文件是工程事实材料，不是本人创作声明或正式申报。** 参赛者应核对实现与来源，并按向组委会确认的规则提交。

- 项目名称：ExampleLoom（示例织机），示例驱动的数据转换引擎与独立工作台。
- 核心语言：MoonBit。核心解析、程序搜索、解释执行、日期校验、歧义选择、配方与批处理均为 MoonBit；JS 是界面、文件 I/O 与调用适配。
- 独立性：不依赖维护者旧项目、Excel、PROSE SDK 或云 API。新目录、新代码和新历史；没有复制旧项目核心代码。
- 功能与准确边界：见 README、ARCHITECTURE；不要写成通用 AI、任意表格转换、自动保证正确、算法首创、全球无竞品。
- 场景：v0.3 建议重点核对条件供应商编码、上下文正则 ref 捕获、宽表到长表；另有连续行打包和含空表头的 Melt 流程。完整输入、操作、输出与验证见 CAPABILITIES 和 examples。这些是构造数据演示，不是客户采用证明。
- 核心技术：有限 DSL 的输出引导搜索、保留多种解释、真实行上的分歧分组、带预算状态、可移植 AST、按列名绑定、多字段批处理。PBE 与交互消歧已有成熟研究，项目贡献是独立实现与可用交付。
- 测试与运行证据：见 VALIDATION。申报时核对当前 commit SHA、测试数量和公开仓库状态，不能把配置了 CI 写成远程 CI 已通过。
- 来源与许可证：README/RESEARCH，项目代码 MIT；内置正则子系统采用并修改 MoonBit 上游 Apache-2.0 源码，具体版本和变更见 NOTICE。概念参考和基准来源也需如实披露。
- 竞争与风险：Flash Fill、PROSE、Foofah 已解决相关问题。MoonBit 现有显式数据转换库功能较广；本项目不声称全面替代它们。新颖性判断仍取决于评委，后续需要真实用户和更广泛测试。
- 已有项目：AgentCanary 的策略回放与本项目不同，不能写成已被驳回。WasmSlim/MoonGate 的问题没有通过改名或换账号绕过。
