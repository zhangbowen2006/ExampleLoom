# 供参赛者本人撰写的当前事实材料

当前为v0.15.0；在v0.14.0多表连接学习基础上增加有限的状态筛选后汇总。本文件不作“本人独立撰写申报书”的声明，不能替代个人诚信承诺。

- 项目：ExampleLoom，MoonBit示例驱动的数据转换与多表任务引擎，附独立浏览器工作台与CLI。
- [公开仓库](https://github.com/zhangbowen2006/ExampleLoom)是原ExampleLoom的持续完善版本，应披露原审核关系。
- 核心：MoonBit负责有限程序合成、表达式、结构变换、多源执行及协议；JS负责文件和界面适配，不依赖PROSE/Foofah运行时或云模型执行转换。
- 学习边界：有限语法与预算、1–8对单表训练；支持从1–4批示例学习两个源表的一或两个相等键连接及一步选列/聚合/排序，或有限相等值筛选再汇总。筛选每列最多8种观察值，每假设32次、全请求2048次，触及限额会报告；规范化和按名合表仍需显式声明。
- 实质新增：多键连接及基数约束、按名合表及来源标记、精确普通十进制聚合、跨训练批次的小数证据、确认式执行及可保存DAG任务，v0.14进一步支持有限多表关联学习。
- 三个完整场景：订单关联商品并汇总、跨月供应商结算、库存目录对账。输入、期望和API/CLI/浏览器验证见[报告](V013.md)及[案例](../examples/jobs/)。没有客户采用证明。
- v0.15.0本地 js、wasm、wasm-gc 各183测试通过；四后端及最新版发行按[CI](https://github.com/zhangbowen2006/ExampleLoom/actions)核验。v0.14.0四后端及浏览器流程已通过。
- v0.15新增40组SQLite独立执行构造对照、三个可学习多表案例的API/CLI/真实浏览器流程，以及筛选后精确小数与错误金额验证。[本轮记录](V015.md)。这不是独立抽样的业务集或盲测。
- 独立构造对照：500组连接、250组合表、350组高精度Decimal及88852项PCRE2共同语法比较；不代表完整PCRE兼容。
- Foofah 外部题（本机v0.14.0）：250道原题中225道有答案，自动首选198/225，事后任一候选上界211/225，仍27道失败。[逐题记录](evidence/v0140-benchmark.json)。开发中已接触该数据，非盲测。13题额外意图和19对补样的辅助诊断单列，不加进自动成绩。
- Auto-Tables 额外单类实验：28道转置题原样作为训练，行数和值变化的测试探针由项目自行构造；自动首候选0/28，用户明确指定整表转置后23/28，另5题超列数上限。此类任务用于开发，非盲测，不构成与其它引擎的同机对比。[方法和限制](TRANSPOSE_EVALUATION.md)
- 数值：9007199254740993超过Double精确整数范围，但未超过Int64；真正超Int64验证见256位进位等独立测试。
- 许可：主体MIT；内置正则采用并修改Apache-2.0源码，保留[NOTICE](../LICENSES/moonbit-regexp.NOTICE)。PROSE、Foofah、Polars、pandas等方法和语义参考见[来源](RESEARCH.md)，并非整体移植。
- 旧项目关系：不能把WasmSlim、MoonGate、AgentCanary改名包装为本项目；AgentCanary不应误称已被驳回。涉及其他仓库实际贡献时应披露。
