# 五轮维护的同类调研（2026-11-12）

依据下列项目自身文档和源码核对功能，不把宣传数字当作本机验证结果；没有运行它们的同机速度比较，没有复制本轮参考项目代码。

| 参照与许可 | 已核对功能 | 本轮处理或剩余差距 |
| --- | --- | --- |
| [Foofah 固定源码](https://github.com/umich-dbgroup/foofah/blob/970864cd53b4c774a3dbdf4589d207f57ec63208/foofah_libs/operators.py)，MIT | 整表展平、固定组包装、条件分列、可补空拆列 | 独立实现整表展平、保守空值路由、显式补空拆列；示例不足时保留固定组/整表歧义 |
| [OpenRefine 记录重组](https://openrefine.org/docs/manual/transposing)，代码BSD-3-Clause | 按记录键分段；重复键可产生多行记录；另有notes列 | 新增显式JSON数组列表输出，保存重复值。不同于其多行record布局；notes列语义本轮未实现 |
| [Microsoft PROSE 教程](https://www.microsoft.com/en-us/research/project/prose-framework/tutorial/)，仓库示例MIT | DSL执行语义、witness和排名分离；可自定义语言 | 本轮仅为现有语言增加明确意图约束，未实现通用第三方DSL插件体系 |
| [MoonFrame](https://github.com/ihb2032/MoonFrame)，Apache-2.0；[Mooncakes](https://mooncakes.io/docs/ihb2032/MoonFrame) | 明确的DataFrame、类型/空值、连接、懒查询与多格式I/O | 本项目从示例搜索可重放程序，不提供完整DataFrame、跨表连接或懒查询；不能把CSV/排序/分组重叠当作独有创新 |
| [Latentmachine](https://github.com/Kumagaizo/latentmachine)，MIT | 可检查的确定性转换、浏览器、API/CLI及多格式输入 | 说明离线浏览器与展示规则已有同类。我们的MoonBit核心与整表程序学习有交集和区别；未测其覆盖率，不宣称全面优越 |
| [exform](https://github.com/ingrid-owusu/exform)，MIT | 字符串示例学习、命令行流及程序输出；Pyodide浏览器 | 本轮不增加其他语言代码生成或流式执行；可移植JSON管道不是完整Python/awk代码导出 |

本轮所有公开任务都已参与开发。完整Foofah自动首候选以原预算和原分母统计；用户明确意图不属于原始默认成绩。现有数据不足以保证初审通过，更没有生产采用或季度获奖证据。
